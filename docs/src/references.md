# References

Key references behind DSArith concepts and benchmarks:

1. J. M. Chesneaux, J. Vignes, *The CESTAC Method for Numerical Validation*.
2. J.-M. Chesneaux et al., *CADNA: a Library for Estimating Round-off Error Propagation*.
3. S. M. Rump, *Algorithms for Verified Inclusions: Theory and Practice* (Rump polynomial benchmark context).
4. N. J. Higham, *Accuracy and Stability of Numerical Algorithms*, SIAM.

These works motivate stochastic arithmetic, significance estimation, computational zero, and instability diagnostics used in this package.
